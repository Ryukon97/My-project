# 쿠키 모션

Cookie.prefab의 PlayerCookie에서 Double Jump Frames, Slide Frames, Exhaustion Frames를 교체할 수 있습니다.
각 배열은 왼쪽부터 4프레임 순서이며, Exhaustion Duration 기본값은 1.8초입니다.
이미지의 아래 중앙 피벗과 Pixels Per Unit 190을 유지하면 원래 캐릭터와 크기가 맞습니다.

체력 소진 → 맵/점수/조작 정지 → 탈진 4프레임 → 마지막 쓰러진 자세 유지 → 결과창 표시.
2단 점프는 0.4초 회전 프레임, 슬라이드는 진입 후 낮은 두 자세를 반복합니다.

생성: 내장 image_gen 사용. 기존 쿠키 이미지와 사용자 모션 시트를 참고했습니다.
최종 프롬프트 요약: 기존 황금색 쿠키, 초록 스카프, 갈색 가방과 머리 비례를 유지한 투명 4×3 시트. 첫째 줄 공중 2단 점프 회전, 둘째 줄 낮은 슬라이드, 셋째 줄 탈진 후 쓰러짐. 모든 프레임은 오른쪽을 향하며 변형·글자·배경 없이 제작.

검증: Unity 메뉴 CookieRun/Validate Motion Sequence (MainGame 플레이 중 실행).
검증 항목: 프레임 참조, 2단 점프, 슬라이드 비율, 점프로 슬라이드 해제, 사망 연출 전 결과창 숨김, 연출 후 표시, 재시작 초기화.
