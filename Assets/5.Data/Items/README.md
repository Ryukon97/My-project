# 아이템 SO 편집

- Unity 메뉴에서 **Tools > CookieRun > 아이템 편집기**를 열거나 Item SO를 더블 클릭합니다.
- 왼쪽 리스트에서 아이템을 선택하고 이름·프리팹·교체 이미지를 바꿉니다. 교체 이미지를 비우면 프리팹 이미지를 사용합니다. 이름 버튼 또는 F2로 이름 칸을 선택할 수 있습니다.
- 효과 종류에 따라 점수, 체력 회복량, 지속 시간, 속도 배율, 자석 범위와 끌어오는 속도를 설정합니다.
- 상단 왼쪽 **Map Theme · 맵 테마 SO**에 MapThemeData 에셋을 드래그하면 해당 배경·바닥·장애물 위에서 아이템을 미리 볼 수 있습니다. 이 선택은 게임의 맵 로테이션을 바꾸지 않습니다.
- 상단 미리보기에서 아이템이나 안내 젤리를 드래그합니다. 아래의 추가·삭제 버튼과 X/Y 좌표로도 편집할 수 있습니다. X는 구간 시작, Y는 바닥 기준 거리(m)입니다. Undo/Redo를 지원합니다.
- 일반 젤리의 배치는 평지 구간에, 체력/자석/부스터/질주의 배치는 해당 아이템 구간에 적용됩니다. 장애물 주변의 점프 젤리 곡선과 큰 젤리 정점은 게임이 자동 배치합니다. 큰 젤리 SO의 배치 좌표는 분위기 확인용입니다.
- **장애물 보기**, **격자·배치 표시**로 미리보기 표시를 켜고 끕니다.
- 맵 미리보기와 같은 SpriteRenderer·카메라 배율을 사용합니다. **미리보기 화면 > 게임 뷰와 동일**로 플레이 화면 비율을 맞춥니다. 긴 구간은 자동 축소하지 않고 **미리보기 가로 이동**으로 확인합니다.
- **저장** 후 다음 게임 실행에서 반영됩니다. 플레이 중에는 수정이 잠깁니다.

기존 6종 SO는 MainGame에 연결되어 있습니다. 새 SO를 만들거나 복제한 경우 MainGame을 열고 **선택한 SO를 게임에 연결**을 누릅니다. 같은 아이템 종류의 기존 연결을 교체하며 종류별 하나만 사용합니다.

## 큰 별 젤리 보너스

큰 별 젤리의 효과는 **모아서 보너스 스테이지**입니다. 기본값은 5개 수집 시 5초이며, 아이템 편집기의 **필요 획득 개수**, **보너스 지속 시간**, **보너스 맵 테마 SO**에서 바꿉니다. 큰 별 젤리의 획득 점수도 함께 적용됩니다.

보너스 중에는 무적이며 체력이 줄지 않습니다. 장애물과 구덩이 대신 연속 바닥과 젤리 3줄이 생성됩니다. 일시정지와 복귀 카운트다운 중에는 보너스 시간도 멈춥니다. 종료하면 현재 거리에 맞는 일반 테마와 안전한 바닥으로 돌아옵니다. 큰 별 젤리를 다시 필요한 개수만큼 모으면 재입장할 수 있으며, 다시 시작하면 수집 개수가 초기화됩니다.

아이템 SO의 보너스 테마를 비우면 MainGame의 **BonusMap**을 사용합니다. 미리보기의 **Map Theme**는 별도로 선택할 수 있습니다.

자석/부스터/질주의 `랜덤 등장 가중치`는 서로의 상대 등장 비율입니다. 0이면 해당 종류를 랜덤 등장에서 제외합니다. 전체 빈도 배율, 특수 아이템 구간 확률, 체력 아이템 간격은 하단의 게임 적용 설정에서 수정합니다.

기존 프로젝트나 다시 생성한 씬은 **Tools > CookieRun > 기존 아이템을 SO로 변환**으로 연결할 수 있습니다. 기존 SO는 덮어쓰지 않습니다.
