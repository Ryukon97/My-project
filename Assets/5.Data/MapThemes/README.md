# 맵 테마 편집

Unity 메뉴 **Tools > CookieRun > 맵 테마 편집기**를 여세요.
위쪽에는 선택한 테마의 미리보기가, 아래쪽에는 테마 목록 / 상단 장애물 / 하단 장애물 / 바닥 / 뒷배경이 있습니다.

1. 왼쪽에서 기본·숲·돌산·용암·동굴 중 하나를 선택합니다.
   테마 옆 **이름** 버튼 또는 **F2**로 이름을 수정하고, Enter/확인으로 저장합니다. Esc는 취소합니다.
   변경한 이름은 목록·미리보기·게임의 테마 안내에 함께 반영됩니다.
2. High Object에는 슬라이드로 피하는 ObstacleHang 프리팹을 넣습니다.
3. Down Object에는 ObstacleLow, 높은 하단 장애물에는 ObstacleTall 프리팹을 넣습니다.
   각 장애물 슬롯의 **Y 위치 보정 (m)**으로 높이를 조절합니다. `0`은 기존 생성 높이, 음수는 아래로, 양수는 위로 이동합니다. 예를 들어 `-0.1`은 0.1m 아래로 내립니다. 상단·하단·높은 하단 장애물을 테마별로 각각 저장하며, 프리팹이 비어 기본 장애물을 사용해도 보정값은 적용됩니다.
   미리보기는 즉시 갱신됩니다. 실제 플레이에서는 해당 위치에 생성되는 테마의 값을 사용하며, 장애물 이미지와 충돌 판정이 함께 이동합니다. 프리팹의 피벗이나 투명 여백으로 떠 보일 때 이 값으로 맞추세요.
4. Ground와 Back Ground에는 Sprite 이미지를 드래그합니다.
5. **저장**을 누르고 게임을 다시 실행합니다. 위쪽 미리보기에는 변경 내용이 바로 반영됩니다.

장애물의 이미지를 수정하려면 해당 슬롯의 **열기**를 눌러 프리팹의 SpriteRenderer를 변경합니다.
각 테마는 `Assets/2.Prefab/Obstacles/Themes/{테마}`에 독립된 장애물 프리팹을 사용합니다.
종류가 다른 장애물이나 씬 오브젝트를 슬롯에 넣으면 적용하지 않습니다.

SO 데이터는 이 폴더의 01_Basic~05_Cave.asset입니다. 더블클릭하면 편집창이 열립니다.
새 테마/복제 버튼으로 SO를 추가할 수 있습니다. MainGame 씬을 연 뒤 창 아래 **게임 적용 순서**에 추가하고 저장하세요.
순서대로 500m마다 바뀌며, 마지막 다음에는 처음으로 돌아갑니다. 전환 거리도 이 창에서 수정합니다.
빈 슬롯은 건너뛰며, 장애물 슬롯을 비워두면 MainGame의 기본 장애물을 사용합니다.
바닥 이미지는 Sprite / Full Rect로 가져옵니다. 가로로만 반복하며 세로는 원본 Sprite 높이(Pixels Per Unit 기준) 한 장을 사용합니다. 피벗이 달라도 윗면을 캐릭터의 바닥 높이에 맞춥니다. 이미지 전체 배율은 Sprite의 Pixels Per Unit 또는 바닥 프리팹의 Transform Scale로 조절합니다.

기존 데이터가 있는 다른 MainGame 씬은 **기존 테마 가져오기** 또는 Tools > CookieRun > 기존 맵 테마를 SO로 변환으로 옮길 수 있습니다.
이미 SO가 연결되어 있으면 기존 설정을 덮어쓰지 않습니다.

미리보기는 실제 SpriteRenderer와 게임의 카메라·배경·바닥 설정으로 렌더링합니다. **미리보기 화면 > 게임 뷰와 동일**을 선택하면 Game 뷰의 화면 비율을 따릅니다. 16:9·16:10·4:3·9:16도 선택할 수 있습니다. MainGame이 열려 있지 않아도 저장된 씬의 설정을 읽기 전용으로 사용합니다.

장애물의 위치는 아트 확인용 배치 예시이며 플레이 중 생성되는 무작위 패턴과는 달라질 수 있습니다. HUD와 일시정지 창은 미리보기에 포함하지 않습니다.

## BonusMap

`06_BonusMap.asset`은 큰 별 젤리 수집으로 입장하는 무적 보너스 스테이지의 테마입니다. 목록에서 BonusMap을 선택해 배경과 바닥 이미지를 바꿀 수 있습니다. 보너스 전용 테마에는 미리보기에서 젤리 3줄도 표시합니다.

**보너스 전용 테마**가 켜진 SO는 일반 500m 로테이션에서 제외됩니다. 창 하단 **BonusMap · 기본 보너스 테마**에 연결하거나, 아이템 SO의 **보너스 맵 테마 SO**에서 개별 연결합니다. 보너스 구간은 장애물과 구덩이를 생성하지 않습니다.

보너스 배경: `Assets/3.Sprite/Storybook/Background_BonusMap.png`. 내장 ImageGen으로 제작했으며 [제작 프롬프트](BonusMapArt.md)에 원문을 보관했습니다.
